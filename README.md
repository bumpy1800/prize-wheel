# 돌려돌려 돌림판

박람회·부스용 **경품 돌림판**. 설정·재고는 MongoDB에 공유 저장됩니다.

## 실행

Atlas 연결 문자열이 필요합니다. `.env.example`을 참고해 Vercel에 `MONGODB_URI`를 넣으세요.

```bash
npm install
npx vercel dev
```

로컬만 정적 미리보기(`npx serve .`)하면 API가 없어 재고가 저장되지 않습니다.

## 플레이

1. **돌리기!** 버튼 → 휠 회전 → 중앙에 당첨 경품 표시
2. 애니메이션이 끝나면 바로 다시 돌릴 수 있습니다
3. 당첨 시 해당 경품 **남은 수량 -1** (수량은 **관리자 화면에서만** 표시)
4. 수량이 0이 되어도 휠 **영역은 유지**, 이후 추첨에서는 **절대 당첨되지 않음**
5. 비중(%)은 **남은 수량이 있는 경품끼리** 다시 정규화됩니다

## 관리자 UI (숨김)

플레이 화면에는 관리 메뉴가 보이지 않습니다. 아래 중 하나로 엽니다.

| 방법 | 설명 |
|------|------|
| **URL 해시** | `…/index.html#admin` 또는 주소창에 `#admin` 추가 |
| **키보드** | **A** 또는 **ㅁ** 키를 **1초 안에 3번** 연속 입력 |
| 닫기 | `#play` 로 바꾸기 / **Esc** / **관리자 닫기** 버튼 |

관리자에서 설정 가능:

- 경품 **이름**
- **총 수량** (입력하면 **비중 %**와 **남은 수량**이 자동 입력)
- 휠 **비중 %** (수동 수정 가능)
- **남은 수량** (표시만, 수정 불가)
- 영역 **색상**
- 추가·삭제·저장, 기본값 복원

설정·남은 수량은 MongoDB `prize-wheel.configs` 문서(`_id: "default"`)에 저장됩니다. 기기 간에 재고가 공유됩니다.

## 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 플레이어 + 숨은 관리자 마크업 |
| `styles.css` | 레이아웃·휠·관리자 스타일 |
| `wheel-logic.js` | 가중 추첨·재고 차감 (순수 로직) |
| `app.js` | 휠 그리기·회전·UI |
| `api/prizes.js` | GET/PUT 경품 설정 |
| `api/spin.js` | POST 추첨 + 재고 차감 |
| `lib/mongo.js` | MongoDB 클라이언트 |
| `lib/store.js` | 설정 로드/저장/스핀 |
